Green Line & GLX Efficiency Analysis

Data Science

Built a visual analytics project on MBTA Green Line operations, using comprehensive headways data to examine reliability and variability across the system. The work explored three main questions: first, how the Green Line Extension’s consistency differs by time of day; second, how inbound versus outbound trains on the Extension compare to the rest of the line; and third, how travel times between stops reveal unique operational patterns. To answer these, we engineered features for headway computation and stop‑level travel times, then developed interactive dashboards that allow users to filter by branch, direction, and time of day. Together, these methods highlighted challenges of missing or anomalous data, while showing how visual analytics can uncover directional asymmetries and systemic reliability gaps in urban transit.
